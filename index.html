♛ pgnsplit

Split a PGN into chunks of 64 games, one study each. Nothing leaves your browser.

100 % local. No server, no upload, no network requests – the files are read and written inside this tab, then handed to you as a ZIP. Works offline and straight from file://.

What this does

  • Every output file is a copy of a byte range of the input: comments, variations, NAGs, [%cal]/[%csl]/[%evp] annotations, the BOM and the line endings stay exactly as they were. Tag pairs are never modified.
  • Games are found by a small lexer that understands { } comments, ( ) variations, ; comments and % escape lines, so multi-line lecture PGNs split correctly.
  • Files with unbalanced brackets in the source are repaired at the next [Event line, and every repair is listed below.
  • Afterwards the SHA-256 of all chunks is compared with the SHA-256 of the input, so you can be sure nothing was lost.

The 64 comes from lichess: a study holds at most 64 chapters and each game becomes one chapter, so every file here is one study.
